## Дефекты

### P0

**P0-1 · Свежесобранные пункты выбрасываются из сводки за период (ложное «пунктов нет»).**
`message.js:103` → `nowMs: started`, значит у относительного периода `explicit.toMs = started`; `message.js:175` отсекает
`fetchedAt < explicit.toMs`, а `fetchedAt` ставится `isoNow()` при вставке (`store.js:211`), т.е. на 5–14 с позже `started` →
всё, что собрал этот же вызов, отбрасывается. Воспроизведение `/tmp/attack6.mjs`: `started=…:00.400`, пункты с `fetchedAt`
`…:00:00Z / …:00:04Z / …:00:12Z` → после фильтра остаётся только первый. На бою: «сводка за 3 дня/неделю/сегодня» отдаёт
устаревшее либо «За период … пунктов нет (собрано 16 источников)» при только что собранной ленте (пустая БД, после retention).
Ожидалось (FR-2, FR-9, критерий 2): пункты текущего сбора входят в окно, верхняя граница нужна только окнам с концом в прошлом
(«за вчера», «с A по B»). Фактически граница применяется ко всем явным периодам. Проверить: две «сводки за 3 дня» подряд —
новые пункты во второй не появятся.

### P1

**P1-1 · Тема после периода не приоритетнее периода (FR-4).** `route('сводка за неделю по золоту')` → `digest`; `TOPIC_MARKER` смотрится только в начале хвоста (`intents.js:93-98`). Ожидалось (FR-4: тема приоритетнее периода) — `ask`; фактически сводка по всей ленте.

**P1-2 · Знак препинания в конце убивает период в фразах без слова-триггера (FR-1).** `parsePeriod('за 3 дня?') = null` (так же `.` и `,`):
шаблоны требуют `(?:\s|$)` (`digest.js:142-204`), а `periodHint` для таких фраз = `plain` с пунктуацией (`intents.js:107`). Следствие:
`route('а что было вчера?')`, `'с 1 октября?'`, `'что было с понедельника?'` → `ask` (LLM по 24-часовой ленте); без «?» — `digest`.
Ожидалось: U3/FR-1 работают на обычной разговорной фразе. Проверить: `node -e` с этими четырьмя строками.

**P1-3 · «интересно» перебивает период, в предложение попадает мусорный термин (FR-4, FR-12).** `routeInterests` вызывается раньше
разбора периода (`intents.js:83`): `route('интересно, что там за неделю')` → `interests/add`, `target='что там за неделю'`;
`fallbackTerms` отдаёт тот же мусор, и по ✅ он запишется в профиль. Ожидалось (FR-4: период раньше интересов; FR-12: общий термин →
переспрос): сводка за неделю.

**P1-4 · Нет пометки о несобранных медленных источниках (FR-9).** `message.js:158`: `slowPlan = !explicit && slow.length ? … : []`, и ни в `notes`,
ни в `partial`/`unsupported` ничего не добавляется (`message.js:198-200`). Ожидалось (FR-9: «их пункты уйдут в следующую, в сводке пометка»);
фактически каналы/html молча выпадают, а в чате только из медленных источников ответ «пунктов нет (собрано 0)» ложен.

**P1-5 · Период не попадает в контекст вопроса по теме (FR-4).** `answerQuestion` строит окно
`digestWindow({lastSentAt:null, firstWindowHours:24})` = 24 ч (`message.js:431-438`, проверено: `fromMs = now−24ч`), `periodHint` в `ask`
не передаётся. Ожидалось (FR-4: «Сводка по золоту за неделю» — вопрос, «окно уходит в контекст»); фактически ответ строится по суткам.

**P1-6 · >3 терминов / короткий / общий термин — молчаливое усечение вместо переспроса (FR-12).** `addInterestTerms` обрывается на третьем
термине (`interests.js:71`), `cleanTerms` молча выбрасывает термины короче 3 символов и общие слова (`interests.js:132-141`):
`addInterestTerms('', ['a1b','a2b','a3b','a4b','a5b'])` → добавлено 3 без предупреждения. Ожидалось (FR-12: переспрос вариантами, записи нет).

**P1-7 · Удаление термина стирает соседние интересы и оставляет источники-сироты (FR-6, потеря данных).** Профиль из интервью —
«структурированный текст до 500 символов» (`bot/interview.py::PROFILE_PROMPT`), не «термин в строке». `/tmp/attack4.mjs` на
`«Драгметаллы: золото, платина, палладий — глубоко\nAI и робототехника: …»`: `removeInterestTerm(text,'золото')` удаляет всю строку
(платина и палладий тоже), а `interestSourcesFor(удалённая_строка, sources)` → `[]` — источники по термину остаются и продолжают собирать
(FR-6 требует удалить их с items/seen_hashes). Ответ при этом: «🗑 Убрал: <весь блок>».

**P1-8 · Пометка о неполноте истории источников не выводится (FR-3).** `coverageNote` объявлена (`digest.js:321`) и не вызывается нигде. Ожидалось (FR-3, третий пункт): пометка о неполноте; фактически сводка за 7 дней по RSS, отдающему только свежее, подаётся как полная.

  `с 25 по 5` (3 октября) → пустое окно за 2025 год, `с 25 декабря по 2 января` → разобрано как `с 25.12`.
