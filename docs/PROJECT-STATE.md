## 2. Что работает (подтверждено)

- Приём сообщений через вебхук, гейт единственного пользователя (fail-closed), ответы в Telegram.
- Сводка по запросу: быстрый сбор (rss/twitter, ≤ 16 источников, дедлайн ~5 с), отбор
  ≤ 25 пунктов / 45k символов, LLM без thinking, `max_tokens=5000`, чанки ≤ 4000.
  Обрезанный ответ больше не роняет вызов (iter-38): уходит с пометкой, при пустом тексте —
  один повтор с половиной пунктов.
- Период из текста («за 3 дня», «с 12 по 18 октября»), интересы, дедуп, retention — iter-36/37.
- Медленный источник (канал/сайт) обрабатывается после отправки сводки, в остаток бюджета.
- JS-тесты: **102/102** зелёные (20.10.2026, `npm test`).

  старые новости в Serverless-версии недоступны (`docs/tgcloud-migration.md` §13).
- Незакрытые срезы паритета (по миграционному документу): онбординг-интервью/FSM,
  часть CRUD источников с пагинацией, ленивый retention-проход, перенос истории.

  Поэтому «полная неделя за один вызов» невозможна — окно честно усекается с пометкой.
