Семантика периода: конец = `now`; «за вчера» и «с A по B» — конец 00:00 MSK дня после B;
«за N дней» = `now − N·24ч`; «за сегодня»/«с <дата|день недели>» — 00:00 MSK; год текущий,
дата в будущем → предыдущий; «с 1 по 5» без месяца → текущий месяц, конец в будущем → `now`.
Пояс — `users.tz_offset_min` (180) из `store`, не константа. Период >7 дней или «за всё время» →
усечение до 7 дней + пометка; начало в будущем → «этот период ещё не начался», `digests` не пишем.

Семантика интересов: add — LLM-вызов без thinking (≤3 термина, JSON-массив), при сбое фолбэк словами
после маркера, запись только по кнопке; remove — сопоставление по нормализованному вхождению,
0 совпадений → «такого интереса нет» + текущий список, >1 → кнопки (≤5); источник = `kind='rss'`,
`title='Google News: <термин>'`, `origin='interest'`, `topics=[термин]`, URL через
`encodeURIComponent(term)`; при `sources.max` интерес пишется, источники нет — скажи явно.

## 5. Инварианты (ломать нельзя)

- Экранируй `escapeHtml` всё внешнее (термины, заголовки, ошибки) в исходящих текстах.
- Чанки ≤4000 символов с валидным HTML (`chunkMessage`), отправка только после успеха предыдущей.

- Гейт по `chat_id` — первым, fail-closed, на message и callback.
- Никаких новых зависимостей, файловых операций, сетевых таймеров и «фоновых» обещаний.

## 6. Бюджет вызова
