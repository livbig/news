## 3. Решения 10–11.11.2026

1. **Один писатель в базу.** Служба владеет `news.db`; агент и фронтенд ходят в API.
   Скрипты `collect-now`/`digest-now` оставлены для отладки, но при живой службе их не
   запускать (был `database is locked`).
2. **`synchronous = NORMAL` + пачки вставок в транзакции.** На SD-карте FULL fsync на каждую
   строку вешал event loop: `/api/health` не отвечал 20+ с, пока шёл сбор.
3. **Плановые сводки не собирают новости синхронно.** Сбор идёт своим интервалом; перед
   сводкой — только если последний сбор старше часа. Иначе слот 21:00 ждал 2+ минуты сбора.
4. **Анализ — 25–40 пунктов за вызов, догон по 8 пачек.** Готовые выжимки идут в сводку вместо
   сырого текста: вход короче, части не обрезаются.
5. **Источники проверены с Pi.** Выключены 404/429: Yahoo, Kitco, gold.org, banki.ru,
   bcs-express, reddit LocalLLaMA, rbc export; снятые темы Google News (инвест-идеи,
   промпт-инжиниринг) — тоже.
