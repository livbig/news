# AGENTS.md — news/pi (агрегатор на Raspberry Pi)

Правила для людей и ИИ-агентов. Родительские: `../../../AGENTS.md`, `../../AGENTS.md`,
`../AGENTS.md`; при конфликте приоритет у этого файла. Язык — русский.

## 1. Что это

Прод новостного агрегатора на Pi: служба `newsd` (сбор → анализ → сводки 09:00/21:00 + API
и фронтенд) и мост `news-bridge` (живой чат с владельцем через pi, зона `nw-livbig`).
`../tgcloud/` — остановленный контур Telegram Serverless, оставлен как архив/откат.

## 2. Красные линии

1. **Один читатель.** `NEWS_CHAT_ID` — единственный разрешённый чат; нет его — служба не
   стартует (fail-closed). Чужие апдейты бот игнорирует без ответа.
2. **Секреты только в env.** Mac: `~/.config/ai/env/news.env`; Pi: `/etc/news/news.env` (600).
   Токен бота, ключ LLM, `NEWS_API_TOKEN` не печатать, не коммитить, не пересылать.
3. **Один писатель в базу.** Пишет только `newsd` (пользователь `newsd`, файл
   `/srv/news/data/news.db`). Скрипты и агент ходят через API; `sqlite3` руками — нет.
4. **Не править зону руками при живой сессии** (`users/livbig/work/AGENTS.md` — правила
   владельца, агент их ведёт сам; деплой существующий файл не перезаписывает).
5. **Никаких публикаций и трат** без просьбы владельца: репозиторий локальный, git push,
   публикация в интернет, платежи — только по прямой просьбе.
6. **Источник правды — Mac.** Правки только на Pi исчезнут при следующем `deploy.sh`;
   после правки на Pi скажи «перенеси на Mac» и опиши diff.

## 3. Как менять код

1. Прочитай `docs/PROJECT-STATE.md` — что уже работает и что не подтверждено.
2. Правка — минимальная, одна причина (ponytail `full`). Не «улучшай» рядом лежащее.
3. Нетривиальная логика (парсер, окно, слоты, деньги/безопасность) → тест в
   `server/test/*.test.js` (`node:test`, без фреймворков) или `app/test/`.
4. Работа с базой — через `server/src/store.js`, не сырым SQL в вызывающем коде.
5. Правки схемы — `server/src/schema.js` (DDL генерируется в `db.js`); ломающая миграция
   требует `ALTER TABLE` в `openDatabase` и записи в STATE.

## 4. Критерий готовности

«Сделано» = есть выполненная команда:

- `npm --prefix pi/server test` — зелёные (171 тест);
- `npm --prefix pi/app test` — зелёные (21 тест, включая инструменты `news_*`);
- после деплоя: `systemctl is-active newsd news-bridge` и `curl /api/health` → 200;
- сводка: `/tmp/sched.json` (dry-run) или живой слот — без «⚠️» в тексте;
- состояние пишется в `docs/PROJECT-STATE.md` (что проверено, чем).

## 5. Эксплуатация

```bash
bash deploy/deploy.sh                     # деплой (Mac → Pi)
ssh pi 'sudo journalctl -u newsd -n 50 --no-pager'
ssh pi 'sudo systemctl start news-task@collect-now.service'
ssh pi 'sudo systemctl start news-task@sources-status.service'
```

Таймеры: `news-heartbeat` (10 мин), `news-backup` (03:55), `news-upkeep` (04:20).
Если после установки юнита таймер `inactive` — `sudo systemctl restart news-*.timer`
(проверено: `enable --now` после замены файла не всегда стартует).

## 6. Чего не делать

- Не запускать `../tgcloud/` и Python-контур (`../bot`, `../pipeline`): второй потребитель
  апдейтов и вторая база. Вебхук снят — вернуть его значит сломать чат.
- Не добавлять источники без проверки с Pi: часть западных фидов отдаёт 404/NETWORK
  (список битых — `server/src/sources-pack.js`, `BROKEN_URLS`).
- Не отключать `PRAGMA synchronous = NORMAL` и транзакционные пачки: на SD-карте FULL fsync
  вешает event loop (инцидент 2026-11-11, API переставал отвечать).

## 7. Синхронизация с Mac (правило владельца, 17.11.2026)

Источник правды — рабочая копия на MacBook. Pi — исполнитель; рассинхрон лечится коммитами.

- **`/srv/news/server`, `/srv/news/bridge`, `/srv/news/app` — не git-каталоги.** Правку, которую
  нужно сохранить, агент складывает архивом в `/srv/news/users/livbig/work/port-to-mac/` вместе с
  `MANIFEST.md` (что изменено и зачем) и **пишет об этом владельцу**. Mac забирает архив,
  распаковывает как есть и коммитит. Иначе следующий `deploy.sh` вернёт всё назад.
- **`deploy.sh` не применяет расхождения молча.** У него есть `check_drift`: если на Pi есть файл,
  которого нет на Mac (или он новее), деплой останавливается. `FORCE=1` — только осознанно, после
  того как правки перенесены.
- **Рабочие метки не синхронизируются:** `restart.request` и `fact-day-override` (в `.gitignore`,
  исключены из `rsync`). Это состояние самоперезапуска и прогресса курса, оно живёт только на Pi.
- **Секреты — только в `/etc/news/news.env` (600).** В git: код, тесты, доки, `.env.example`.
  Никогда: токены, ключи, базы `*.db`, сессии, PDF клиентов, бэкапы.
- **Репозиторий на GitHub (`livbig/news`) публичный.** В него не уходят chat_id, юзернеймы,
  туннели, IP и правила зон: репозиторий сначала переводится в private (решение владельца).
