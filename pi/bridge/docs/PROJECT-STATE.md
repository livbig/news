## 1. Что это

Мост Telegram ↔ сессии pi: список/открытие/продолжение сессий, параллельные чаты,
команды pi, живой стрим ответа в одном сообщении. Один процесс-бот + по одному дочернему
`pi --mode rpc` на используемую сессию (лениво, гаснут по бездействию).

## 3. Запуск и остановка

```bash
cd ~/Desktop/ai/self/pi-telegram-bridge
npm test
npm run smoke                      # связка с реальным pi без вызова модели
/telegram-bridge start             # штатный путь в pi (пишет pid-файл)
/telegram-bridge stop
```

Ручной запуск (только если штатный недоступен):

```bash
( cd ~/Desktop/ai/self/pi-telegram-bridge && nohup node --env-file=.env src/main.js \
  </dev/null >> bridge.log 2>&1 & echo $! > ~/.pi/agent/pi-telegram-bridge/bridge.pid ) >/dev/null 2>&1
```

Лог: `~/.pi/agent/pi-telegram-bridge/bridge.log` (и копия `bridge.log` в проекте — историческая).
После правок `src/` или `extensions/` живой бот работает старым кодом — нужен перезапуск.
